# PrintPack Studio — Free Research Preview

Turn finished artwork into a small printable download bundle, locally in your desktop browser. Choose paper sizes, adjust each crop, and export print JPEGs with a size guide and a quality report.

**[Download the free trial ZIP](https://raw.githubusercontent.com/wow314/printpack-studio-preview/main/printpack-studio-0.2-trial.zip)** · No payment or application account required.

## Try it in five minutes

1. Download and extract the entire ZIP. Keep all files and the vendor folder together.
2. Read START-HERE.md and open index.html in a current desktop Chrome or Edge browser.
3. Click **Load sample collection** to try the included original demo artwork.
4. Select an artwork and review each size. Each preview has its own fit and crop controls.
5. Click **Build delivery package**, then download and extract every ZIP part.

The build has been tested through a local HTTP preview. Direct file opening still needs confirmation on your browser. If it fails, report the browser and symptom; do not disable browser security.

## What is included

- Standard and custom paper sizes, with independent crops.
- Named size presets stored on your device.
- Print JPEGs, a print-size card, a reference preview, a buyer print guide and a quality report.
- One product listing per workspace: up to five ZIPs below 19 million bytes each.

## Current limits

This is an early prototype, not a finished commercial product. It has not yet been validated with external sellers.

Up to six JPEG/PNG/WebP originals, 24 MB and 40 megapixels each. Small originals are not enlarged. Artwork and crop edits are temporary: download results before closing or refreshing. Only named presets are saved. Browser JPEG output is not CMYK proofing and does not preserve original ICC/EXIF profiles. Marketplace acceptance is not guaranteed.

Images are processed locally. The application has no artwork upload, analytics, cloud account, checkout or automatic listing publication.

## Help us test a real workflow

If you already prepare printable artwork, try one artwork with the sizes you normally deliver. Then **[open a feedback issue](https://github.com/wow314/printpack-studio-preview/issues/new)** with:

- Your browser and operating system.
- Your usual tools and approximate time for the same task.
- Whether you tested the samples or your own real workflow.
- Whether you could download and inspect every file; any errors or confusing steps.
- What you would keep using instead, and why.

Honest negative feedback is welcome. TEST-FEEDBACK.md in the ZIP has optional follow-up questions. Issues are public: do not post private artwork, customer details, passwords or payment information. No purchase is requested.
